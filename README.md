# Tashi Dendup — Portfolio

A self-contained, dependency-free portfolio built for direct deployment to Vercel.

## Features
- Responsive dark premium UI
- Animated particle/network background
- Cursor spotlight and parallax layers
- Magnetic buttons
- 3D card tilt
- Scroll reveal and progress indicator
- Animated counters and performance bars
- Animated backend architecture diagram
- Animated terminal profile
- Reduced-motion accessibility support
- No npm dependencies or build step

## Deploy to Vercel
Import this folder/repository into Vercel. No framework preset or build command is required. Or connect with github.
